# Documentos da empresa

Coloque aqui os PDFs originais. O modo `mapear` da skill `edital-delta` lê esta
pasta e transcreve o conteúdo para `../00-CONTEXTO.md`.

O que costuma ser exigido em habilitação:

| Documento | Serve para |
|---|---|
| Cartão CNPJ | identificação, CNAE, porte ME/EPP |
| Contrato social e alterações | representação legal, objeto social |
| Balanço patrimonial registrado | qualificação econômico-financeira (LC, LG, SG, CCL) |
| Atestados de capacidade técnica | qualificação técnica: experiência, volume, escopo |
| Certidões (federal, estadual, municipal, FGTS, trabalhista) | regularidade fiscal |
| Certificações (ISO, CMMI, MPS.BR, CFPS) | quando o edital exigir |

Rascunho sem assinatura não é documento. Se estiver aqui, será listado como inválido
no contexto, nunca como comprovação.
