# Editais

Uma pasta por certame. Dentro, os PDFs oficiais:

```
editais/{orgao}-{modalidade}-{numero}/
  EDITAL.pdf
  Termo de Referencia.pdf     ← concentra a qualificação técnica
  ETP.pdf                     ← consulte quando o valor estimado for sigiloso
  Anexo-*.pdf
```

Planilha de lance e arquivo de trabalho podem ficar na pasta, mas são ignorados na
extração de requisito. Só documento oficial vira requisito no parecer.
